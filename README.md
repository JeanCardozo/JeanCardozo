# Jean Cardozo — JeanCRG

Fundador de **JeanCRG, IA para negocios** (Ibagué, Colombia).

Construyo asistentes IA de WhatsApp y automatizaciones para pymes: sistemas que responden 24/7, recuperan ventas que se pierden cuando nadie responde y eliminan el trabajo repetitivo. Todo sobre la API oficial de Meta (WhatsApp Cloud API), n8n y Supabase, con seguridad desde el diseño.

---

## Qué construyo hoy

- **[chatAI](https://github.com/JeanCardozo/chatAI)** — Sistema vendible de asistentes IA para WhatsApp: Meta Cloud API → n8n → IA (Gemini / DeepSeek) → Supabase multi-tenant, con verificación de firma HMAC, validación de entrada y RLS. Incluye esquema multi-tenant por cliente, prompt maestro con contrato de salida y kit de venta completo.
- **[OpenWA](https://github.com/JeanCardozo/OpenWA)** — Gateway para la WhatsApp Cloud API de Meta.
- **Automatización de procesos con n8n** — flujos que conectan WhatsApp, CRMs, bases de datos y reportes para eliminar tareas repetitivas.

## Stack

n8n · Meta WhatsApp Cloud API · Supabase · PostgreSQL · TypeScript · Node.js · React · Flutter · Docker · Python · Linux
