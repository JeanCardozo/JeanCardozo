## Sobre mí

Desarrollador Full Stack obsesionado con el rendimiento web. Construyo aplicaciones rápidas, accesibles y mantenibles con Astro, React, TypeScript y Node.js. Me especializo en arquitecturas static-first, Astro Islands e hidratación parcial para lograr sitios que cargan instantáneo.

- **Rol actual**: Full Stack Developer en Distribuciones La Herramienta
- **Enfoque**: Rendimiento web, TypeScript strict, SSG, Zero JS
- **Ubicación**: Ibagué, Colombia — 100% remoto

## Proyectos destacados

### [ComponenteVelada](https://github.com/JeanCardozo/ComponenteVelada) — [Demo](https://componente-velada.vercel.app/)
**Astro 6 + React 19 + Tailwind 4 + TypeScript strict**
Componente web de alto rendimiento para La Velada VI. SSG con Astro Islands, hidratación parcial y cero JS en producción. Lighthouse perfecto, arquitectura de componentes limpia.

### [scraper-challenge](https://github.com/JeanCardozo/scraper-challenge)
**TypeScript, fast-xml-parser, Vitest**
Scraper para sistemas JSF/PrimeFaces con paginación AJAX, cola de descarga con backoff exponencial y 36 tests unitarios. Arquitectura basada en adaptadores.

**JavaScript, Firebase**
